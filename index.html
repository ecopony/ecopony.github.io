About

I'm a software developer based in Arizona, and I make maps.

I build software for a living and make maps on my own time. I earned a Master's degree in Geographic Information Science in 2023, and my work since then combines code and cartography.

My main interests are terrain visualization, watershed analysis, and data-driven maps generated with code. I write about this work on Medium.
